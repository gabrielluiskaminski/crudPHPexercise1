Explicação da execução do fluxo do código.

Preciso explicar o fluxo de execução deste codigo, vou escrever e voce analisa o que eu errei:
Primeiramente nos temos o compose.yaml que vai construir os dois container com as imagens que vão ser criadas a partir dos dois Dockerfiles em frontend e backend.
No Dockerfile do backend ele vai construir o container a partir de uma imagem que ja vem o php 8.3 cli instalado e vai usar a pasta /app. Na pasta app ele vai copiar os arquivos confi, public, src e data para dentro da pasta e vai dar permissão para todos lerem, escreverem e executarem a pasta data. Apos isso vai usar o expose para indicar a porta que vai ser usada que é a 80 e vai rodar o comando no cmd php -S 0.0.0.0:80 -t public public/index.php que vai ordenar o container para usar a porta 80 para comunicação e executar o servidor php. O -t vai tornar a pasta public como root do programa e vai indicar o index.php para começar o programa quando aparecer uma requisição.
quando chamado o index.php vai primeiramente buscar pelo caminho literal e incluir os arquivos do config.php, apos vai criar a variavel origin que vai receber do array associativo o valor da chave ['HTTP_ORIGIN'], caso não tenha nenhum valor vai receber apenas uma aspas simples. Apos ele vai executar um operador ternario que verifica se o valor de $origin está em $allowedOrigins que esta no config.php, e se for verdade ele envia um cabeçalho HTTP liberando um acesso desta origem especifica para o navegador. Depois disso ele define os metodos aceitos no cabeçalho, o tipo de resposta que o servidor espera do navegador e o tipo do body da resposta HTTP. Depois disso ele verifica se o metodo de requisição HTTP é options, se for options significa que o navegador está perguntando para a api
